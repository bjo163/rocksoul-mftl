# Public / Operator Boundary

## Public

Public consumers may read:

- canonical STORY records;
- claims, sources and evidence;
- claim challenge projections;
- narrative drift records;
- epistemic benchmark metadata;
- reviewed public cross-domain edges from `rocksoul-correlation`.

Public views must keep uncertainty, provenance, counterevidence and owner boundaries visible.

## Operator

CRAYON owns:

- investigation workspaces;
- unpublished hypotheses;
- entity reconciliation proposals;
- review checklists and decisions;
- temporary AI analysis;
- moderation or private submission state;
- publication orchestration.

An operator draft is never public truth merely because it exists in CRAYON.

## Publication path

```text
CRAYON DRAFT
   ↓ review
OWNER REPOSITORY CANONICAL RECORD
   ↓
CORRELATION REVIEWED EDGE
   ↓
PUBLIC WEB / API
```

This separation prevents a convenient console cache or AI draft from becoming accidental canonical ownership.
