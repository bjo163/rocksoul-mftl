# Contributing Data

Create one canonical JSON record per myth/tradition item under:

`data/records/<region-or-country>/<ID>.json`

Before submitting:

- validate the record against `schemas/myth-record.schema.json`;
- ensure every factual claim has `source_basis`;
- use stable IDs;
- avoid duplicate entities/aliases;
- distinguish historical attestation from truth claims;
- keep theological assessment separate;
- mark uncertainty explicitly.

Do not use the example record as evidence.
