# Changelog

All notable changes to MFTL are documented here.

## [0.4.0] — 2026-09-08

### Added

- P0: Narrative Drift Timeline, Claim × Evidence Matrix, Benchmark 25 grid, autonomous research queue;
- P1: Source Lineage, Evidence Coverage heatmap, geographic coverage map, Conspiracy Narrative lane, Freshness timeline;
- P2: Cross-Rocksoul qualified-reference explorer, confidence distribution, research velocity;
- build-generated observatory analytics from records, candidates, claims, sources, evidence, benchmark and drift data;
- autonomous seven-lane Scout → Intake → MFTL Steward → dev → CI → main flow.

### Changed

- branch contract is now `dev → main → release`;
- corpus index advances to `corpus-index.v0.5`;
- package version advances to 0.4.0.


## [0.1.0] — 2026-09-07

### Added

- provenance-first world myth corpus foundation;
- canonical myth record JSON Schema;
- discovery candidate staging schema;
- record-type taxonomy;
- theological pattern taxonomy;
- corpus validation tooling;
- GitHub Actions validation/build workflow;
- research, automation, contribution, and data-model policies;
- React + Vite + TypeScript public research-site foundation;
- documentation hub and dataset citation metadata;
- hourly evidence-first research automation;
- main-only working-branch contract.

### Project status

**Foundation.** The next milestone is corpus depth: reviewed records, regional coverage, explorer UI, source panels, graph visualization, and explainable Mizan assessment.
