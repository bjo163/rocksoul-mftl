# General MFTL Objects

This directory stores non-myth canonical objects using `schemas/mftl-record.schema.json`.

Examples include prophecy records, integrity cases, deviation cases, event reports/event claims, pseudohistory cases, artifact-context records, and comparison objects.

Canonical historical events belong to `rocksoul-legend`. MFTL objects may describe or reference an event as narrated/claimed, but should not duplicate a defensible LEGEND `EVT-*` record.

Existing myth records remain in `data/records/` and continue using the specialized myth schema.
