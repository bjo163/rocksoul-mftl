# Source Registry

> **/// NO SOURCELESS LORE. ///**

Sources are reusable first-class provenance objects. Missing evidence stays missing; it never gets repaired with an invented citation.

Source records are first-class objects in MFTL.

Store reusable provenance here rather than copying incomplete citation metadata into every record.

Canonical source IDs use:

`SOURCE-<REGION-OR-DOMAIN>-<TOKEN>`

Each source may support, contradict, contextualize, or provide an alternative explanation for multiple claims through `data/evidence/`.

Do not create source records for fabricated or unverifiable citations. A missing source is better represented as unresolved than invented.
